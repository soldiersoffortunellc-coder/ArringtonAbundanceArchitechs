# 07 — Executive Command Center Specification

Implementation: `dashboard/index.html` (reads `dashboard/dashboard_data.json`,
generated by `scripts/run_demo.py`).

## Sections

1. **90-Day Revenue Model** — modeled 90-day target for the active
   scenario, contracted revenue, cash collected, MRR, accounts receivable,
   refunds. Contracted and collected are always shown as separate cards,
   never combined.
2. **Pipeline & Conversion** — pipeline value, close rate, show rate,
   proposal rate, leads generated, qualified appointments.
3. **Client Health & Delivery** — implementation capacity used, average
   time-to-launch, QA pass rate, average gross margin (with a count of
   accounts below the required margin), onboarding live/blocked counts.
4. **Market Opportunity Ranking** — every scored industry vertical with its
   normalized score and Activate/Test/Pause/Reject recommendation.
5. **Open Executive Escalations** — the CEO agent's aggregated escalation
   feed across every C-suite agent, refreshed every cycle.
6. **C-Suite AI Agent Roster** — all 13 agents, their mission statements,
   and reporting lines, rendered directly from `agent_roster()`.

## Data flow

```
scripts/run_demo.py → RevenueOperatingSystem.run_cycle() → dashboard_data.json → dashboard/index.html
```

No live data source is wired in yet (no GHL credentials — see docs/09). In
production this dashboard would be re-pointed at a real API surface that
calls `RevenueOperatingSystem.run_cycle()` against a real `GHLAdapter` and
real tenant data; the HTML/JS layer does not need to change, only the data
source.

## Fields required later that are NOT modeled yet

Per the "Results by industry / offer / salesperson / acquisition source"
requirement: the underlying `SalesPipeline` and `BillingLedger` already
carry `industry` and `source` on every opportunity/tenant, so these
breakdowns are a straightforward aggregation once there's real multi-tenant
data to aggregate — intentionally not built against a single-cycle demo
dataset where the breakdown would be trivial/misleading.
