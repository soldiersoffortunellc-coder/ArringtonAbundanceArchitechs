# Webinar Presentation Outline

45-60 minutes, industry-specific version delivered per vertical (do not
run one generic cross-industry webinar — attendees self-select by
industry-specific registration page, per `sales-assets/landing-pages.md`
patterns).

1. **Hook (5 min)** — the cost of the named problem, in the audience's own
   terms (missed calls, dead leads, recruiting churn) — sourced from real,
   attributable examples or clearly-labeled illustrative scenarios, never
   presented as guaranteed outcomes.
2. **Why generic CRMs fail this industry (5 min)** — ties directly to
   "Do not create a generic CRM product" positioning.
3. **Live walkthrough of the industry system (20 min)** — condensed
   version of the demo script (`sales-assets/demo-scripts.md`), the 3-4
   highest-impact moments only.
4. **How implementation actually works (5 min)** — onboarding state
   machine in plain language, sets expectation on timeline.
5. **Q&A (10-15 min)** — live, unscripted; objection-handling library on
   hand for the presenter, not read verbatim to attendees.
6. **Offer (5 min)** — the relevant tier, with a time-bound webinar-
   attendee incentive if the CRO has approved one (never a fabricated
   scarcity claim).
7. **CTA** — book a discovery call, link to qualification form.

## Follow-up

All attendees enter the appropriate industry nurture sequence; no-shows
get the replay plus a direct discovery-call CTA.
